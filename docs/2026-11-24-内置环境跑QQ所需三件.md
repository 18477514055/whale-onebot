# 内置环境（whale-environment）里让 QQ 客户端跑起来，需要补齐哪三样

> 2026-11-24 真机实测记录。适用对象：**新装包 / 并排测试包** 这条「APK 自带环境」的新路径。
> 老 rootfs（完整 Debian 骨架）没有这些问题，所以历史上一直不暴露。

## 先记住这条结论

`whale-environment`（51 MB / 892 条目）**不是完整 Debian**，它是「只够跑 node 的迷你系统」：

| 目录 | 实际有什么 |
|---|---|
| `bin/` | 只有 `bash`、`sh` |
| `usr/bin/` | 只有 `bash`、`env`、`sleep`、`node` |
| `lib/aarch64-linux-gnu/` | glibc 核心（`libc`、`libdl`、`libgcc_s`、`libpthread`、`librt`）、证书等 |
| `etc/debian_version` | **不存在** |
| `opt/whale/` | `instance-app`、`host-adapter`、`instances`、`bili-protocol` —— **没有 `native/`** |

⇒ 任何「在容器里跑 shell 脚本」的路径（`rm`/`mkdir`/`cp`/`tar`/`xz`）都会在真机上报
`/bin/bash: line 1: rm: command not found`。**解包类操作必须放宿主侧**（见下）。

## 三样必须补的东西

### ① 登录脚本与 `qq-state`
`ContainerService` 曾经只对**老 rootfs**（`!managedImage`）释放 `container-login.mjs` 和建 `qq-state` 目录，
而内置环境正好是 `managedImage` ⇒ 容器里根本没登录脚本 ⇒ 点扫码什么都不发生。**现已改为无条件释放。**

### ② native 桥（`/opt/whale/native/`）
`container-login.mjs` 第一件事就是 `process.dlopen('/opt/whale/native/loader.node')`，缺了直接
`FATAL … cannot open shared object file` + `LOGIN: exit rc=1`。

四份产物（ARM64，本地编译，随 APK 的 `assets/native/` 发）：

```
loader.node               69144
libonebot-node-host.so    78704
consumer.node             69952
probe.node                79696
```

**技术债**：`loader.node` 的 `DT_NEEDED` 写死了编译机绝对路径
`/mnt/d/qq-onebot/.tmp/native-host-arm64-0wfTF4/libonebot-node-host.so`。
老 rootfs 当初就是靠把 `.so` 摆到该路径跑通的，`ContainerService` 现在照抄一份到同一路径。
根治要重编 loader.node 加 `$ORIGIN` RPATH，然后删掉那段补偿。

### ③ 一整套图形/网络库
`wrapper.node`（QQ 的 Electron/Chromium 部分，147 MB）链接了一堆系统库。逐层撞出来的是：

```
libX11.so.6 → libgssapi_krb5.so.2 → libbsd.so.0 → …
```

处理办法：从一台**已经有完整 Debian rootfs** 的机器上只读拉取（`adb exec-out run-as … cat`），
放进 `android/app/assets/native/gui/`，运行端释放进 `rootfs/usr/lib/aarch64-linux-gnu/`。

- 当前策略：「`usr/lib/aarch64-linux-gnu` 里体积 ≤ 1.2 MB 的实体库全要」+ X11/glib/vips/krb5 家族
- 规模：**525 个文件 / 约 104 MB**（含实体与 SONAME 别名）⇒ APK 从 55 MB 涨到 **104 MB**
- 重新生成：`.tmp/pull-gui-libs.mjs`（按名字模式）+ `.tmp/pull-small-libs.mjs`（按体积）
- `android/app/assets/native/**` 已进 `.gitignore`（不进版本库）

屏幕：二维码完整显示 + 「N 秒后过期」倒计时。

## 排障入口（以后先看这两个）

1. **`adb logcat -s WhaleLog`** —— `ContainerService.logLine()` 现在同时写 logcat。
   release 签名的并排包没有 `run-as`，这是唯一能看到容器内发生了什么的地方。
2. `files/logs/container.log` 与 `rootfs/opt/whale/qq-state/login.log`（debug 包才读得到）。
