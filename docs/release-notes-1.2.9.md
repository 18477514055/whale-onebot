# Whale OneBot v1.2.9（第三阶段本地验收包）更新说明

> **版本**：`1.2.9`（`versionCode 12010`）｜**内置核心独立部件**：`bot-core-1.2.9.zip`  
> **定位**：中量级 Hindsight 记忆架构（6 维立体人物画像 + 自动新替旧留痕 + 越用越牢巩固曲线 + 共用三层语义引擎 + 手机多文件直接导入 + 跨平台通用）  
> **数据安全**：严格遵循老数据只读/只追加原则，旧聊天记录、旧人物印象、旧长期记忆平滑升级零丢失。

## 一、这一版让机器人的“大脑”进化了什么？（大白话）

### 1. 分抽屉记忆 + 6 维立体人物画像库（参考 Hindsight 轻量化实现）
- **4 个清晰抽屉不混杂**：人物档案与 6 维画像 / 最近发生的事 / 带分类标签的长期卡片（约定、偏好、规则、事实等） / 本群梗库与已核验纠错教训，各自清晰分栏，绝不揉成一锅杂乱流水账。
- **6 维立体人物画像**：为活跃常客自动建立并增量丰富 6 个维度——**基本身份与背景 / 性格与说话风格 / 兴趣爱好与常聊话题 / 沟通偏好与雷点边界（互动习惯学习） / 彼此关系与共同梗 / 近期动态与约定**。
- **极省钱硬闸门**：路人（发言 `< 15` 句）零模型调用；常客只有累计 `≥ 15` 句且**距离上次整理确实新说过 `≥ 5` 句**时，才搭现有后台整理的顺风车一起增量更新，彻底不空烧沉寂老熟人。

### 2. 自动「新替旧」留痕 + 真人「越用越牢、久置沉底」曲线
- **情况变了自动更新，老记录绝不硬删**：搬家、换工作、喜好变化时，新记忆自动顶替旧记忆，旧版本会标为「已过时」留痕（聊天不再引用，手机上随时能翻看并一键恢复；你手写的印象永远最高优先级、绝不被自动修改）。
- **只调排序不删数据**：常被聊起、被回忆巩固次数多的记忆越排越靠前；陈年琐事自然沉底不再抢占聊天空间，真被问到依然翻得出来。

### 3. 记忆库与知识库共用「三层语义检索引擎」
- **第 1 层（在线向量 API）**：自动复用你在手机「知识库 / 模型与 Key」里已经配好的向量模型，不用碰环境变量。
- **第 2 层（纯离线几十 MB 轻量中文向量包）**：支持纯 Node.js 零原生依赖的二进制静态中文向量包（`WZVEC001`），毫秒级计算、不挑手机芯片、支持在 App 里通过安全 https 链接下载校验并即刻生效。
- **第 3 层（零配置垫底）**：就算不联网也不下模型，内置 **FTS5 高速全文 + 中文高频近义词扩展 + 实体关系图谱一跳扩散 + RRF 融合排序** 依然开箱可用。
- **淘汰只读不写的旧向量孤岛**：新记住或整理完的人物印象会在后台静默同步写入纯 SQLite 向量（不卡聊天），手机端提供「一键为老印象补齐语义向量」。

### 4. 纠错学习增强 & 手机多选文件直接导入
- **查记忆也优先尊重纠偏**：机器人调用 `memory_query` 支持按抽屉筛选（全部/人物/事件），并自动优先带出本群之前已核验过的纠错教训，防止反复犯同一个错。
- **告别手工拷容器路径**：手机「知识库」页和「记忆 → 工具箱」页新增系统多选文件选择器，直接多选 `.md / .txt / .json`：
  - 导入**知识库**：立刻入库并安全带事务建全文索引（0 模型费用）；
  - 导入**记忆库**：进入后台安全队列消化为 6 维人物画像或背景记忆卡片，进度可随时查看。

### 5. 打破“只认 QQ 号”限制，跨平台通用（默认按平台隔离）
- 亲密度、加减分事件、人物画像与长期记忆全面放宽，支持 QQ、B 站（`bilibili:<id>`）、抖音（`douyin:<id>`）等平台标识，默认按平台隔离互不串号，界面友好展示平台标签。

## 二、手机 App 新增看得见、点得到的功能

1. **看板 → 记忆 → 人物**：点开人物详情，清晰展示完整的 **6 维立体人物画像** + 最新近况 + 相处转折里程碑。
2. **看板 → 记忆 → 长期记忆**：新增**按分类筛选**（约定 / 偏好 / 规则 / 事实 / 事件 / 项目 / 画像），并显示每条卡片的**已巩固次数**。
3. **看板 → 记忆 → 工具箱（新增）**：
   - 查看当前生效的三层语义引擎与印象向量覆盖率，支持**「一键为老印象补齐语义向量」**与**「下载安装离线轻量中文向量包」**；
   - **「从手机多选文件导入记忆库」**（提炼为某人 6 维画像 / 导入背景记忆卡片）+ 实时任务进度；
   - **「已过时 / 被替换的旧记忆」**查看与**一键恢复**。
4. **设置 → 知识库**：新增**「从手机多选文件导入资料」**主按钮，并展示共用三层语义引擎状态。
5. **看板 → 亲密度与心情**：榜单与单查支持显示平台标签，单查支持输入 QQ 号或 `bilibili:` / `douyin:` 跨平台 ID。

### 本轮发版链做对了两件事

1. **索引 `current` 跟上版本**：内置核心已前插 `1.2.9`，但 `current` 原来还写 `1.2.8`（沿用上一版索引时漏改）。已改正并重算哈希；`releases[]` 仍与 1.2.8 深相等 —— 已装 1.1.x 的旧 App 不受影响。
2. **滚动指针第一次真正滚起来**：把 pin 重钉到 `v1.2.9/release-index.json`，同时把 `core-channel-v1` 的 `channel.json` 重签为 **`sequence = 2`**（指向 1.2.9 索引、180 天有效）。1.2.8 及以后的 App 会自己顺着这条路走到新索引，**不需要等新 APK 才知道有新核心**。

校验链自检 **17/17 通过**：`pin 无 BOM → url 指本版 → pin.sha == 索引字节 sha → schemaVersion 2 → current 正确 → releases[] 深相等 → core 字节数与 sha 一致 → manifest.sha 一致 → manifest 内 350 个文件哈希全对 → SHA256SUMS 3 条全对 → channel 指向本版且 sequence=2`。
