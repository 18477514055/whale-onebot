# 知识库使用说明

机器人的知识库是「你自己的资料文件」+「一份索引」。它不会把资料塞进每次对话，只有聊到具体名词、
模型觉得自己不确定时，才会去查一下。

## 三步上手

1. **放资料**：把文件放进手机里容器的 `/agent/data/knowledge-inbox/<库名>/` 目录。这一层需要借助电脑，见下一节。
2. **新建库**：App → 配置 → 知识库 → 资料库与向量模型 → 新建资料库。填名字，选文件后缀（默认 `.md,.txt`）。
3. **建索引**：目前没有入口（面板没有按钮，容器里也没有脚本）。没有索引的库会显示「未索引」，也搜不到内容。

第 3 步是这一版缺的功能，不是操作错了。

## 资料怎么放进去

App 的数据在应用的私有目录里，普通文件管理器进不去。目前可行的方式：

- **电脑 + adb**（推荐）：手机连电脑，用 `adb push` 把文件推进 `/data/local/tmp/`，再用
  `adb shell run-as com.whaleonebot` 拷到 `files/rootfs/agent/data/knowledge-inbox/<库名>/`。
- **手机 root 后用文件管理器**：能直接进应用私有目录，但手机必须先 root。

App 内没有上传按钮，也没有给使用者的终端页面。

## 向量模型

面板上有两张卡：向量模型（知识库与记忆库共用）和重排模型（记忆召回排序用）。

- 不填也能用：会跟随「模型与接口」里配置的渠道，默认模型 `BAAI/bge-m3`。
- 想单独指定：填提供方、模型名、密钥。密钥只写入，界面不会回显。
- 改完立即生效，不用重启机器人。
- 想撤销：卡底部有「恢复跟随渠道」，点它清掉这一类的三项。

## 常见问题

**怎么知道库有没有索引？** 资料库行上会显示段数；显示「未索引」就是还没建。

**删库会不会删文件？** 不会。删除只是把它从库清单里移除，`index.sqlite` 里的索引行和磁盘上的文件都不动。

**换向量模型要重建索引吗？** 同族模型（例如 `BAAI/bge-m3` 与旧索引使用的那批向量）在同一向量空间，不用重建。
换成别的族就需要重建，现在还没有重建入口。

**为什么资料不会被塞进每轮对话？** 检索是工具调用，平时不参与提示词拼装。这样既省上下文，也不会因为资料写错而污染人设。

**向量服务挂了会怎样？** 关键词检索仍然工作，只是「说法不同但意思相近」的内容可能搜不到。不会报错，也不会阻塞回复。

## 这一版做不到的事

- 在面板里给库建索引（需要长任务和进度显示）。
- 从手机面板直接上传文件。
- 下载本地的小向量模型（现在只能用外部 embedding 服务）。
