# Whale OneBot 1.2.1

这是一次**纯修复**：解决「1.2.0 里点版本会弹出一个什么都点不动的资产清单，导致根本没法更新」的问题。

## 问题是什么

1.2.0 的版本管理页里，点任意一个版本会弹出一个弹层，把该 Release 的**全部发行资产逐条列出来**——
环境包、核心、两个插件、三份合规源码，每一行还带完整 URL。那个弹层**只能看、没有任何可点的动作**，
于是用户被卡死：既更新不了 App，也复制不了链接。

## 现在怎么用

1. 进「版本管理 → App 版本」，列表里**点一下某个版本**（比如 `v1.2.1`）—— 该行会高亮成选中态。
2. 列表底部有一个按钮，会从「先点一下上面的版本」变成 **「下载并更新到 v1.2.1」**。
3. 点它 → 系统下载器开始下载 APK → **下载完成后自动拉起系统安装器**，确认安装即可。
4. 如果系统提示「不允许安装未知来源应用」，点一次允许（会跳到对应设置页），回来再点更新就行。

- **那个资产清单弹层已经整个删掉**，不会再出现。环境包/核心/插件这些东西在「内置部件」卡里各自有下载入口，
  不该和「换 App 版本」挤在一起。
- 已经是当前版本时，按钮显示「已是最新（tag）」并置灰；该版本没有 APK 资产时显示「该版本没有 APK 安装包」。

## 安装与回退

- 覆盖安装即可，**不需要卸载**：环境、核心、QQ 登录态、知识与记忆库都保留。
- 版本号：`12002` / `1.2.1`（release 签名，无 `debuggable`）。
- 内置部件（环境 1.1.8 / 核心 1.1.8 / 两个插件 1.1.8 / 三个 1.2.0-beta.1 的后端与桌面协议端）
  与 1.2.0 **一个字节都没改**，仍在 `v1.2.0` 那个 Release 里，索引也还是同一份（sha256 `6fe52de1…`）——
  所以这一版**只发了 APK**，pin 不用改。

## 已验证 / 未验证

- 已验证：全量 `javac` 通过、逻辑测试全绿、三个包逐个核过包名/versionCode/`debuggable`/签名/sha256，
  `REQUEST_INSTALL_PACKAGES` 确认进了包。
- **未验证**：这一版仍然**没有上真机**（大文件只能走 USB，当时链路不通）。「点版本 → 下载 → 拉起安装」
  这条链路的实机表现请你装完告诉我；尤其是：
  1. 点版本后行有没有高亮、底部按钮文案有没有变；
  2. 下载完成后有没有自动弹出安装器；
  3. 如果被「未知来源」拦住，跳设置页是否正常。
