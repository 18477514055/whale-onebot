# B站账号动作：启动、发现、验收

这是可单独部署的 OneBot 协议端。它不是给官方客户端安装插件，也不会给原有私信机器人自动增加账号权限。旧版文本私信的实际收发证据见[私信接入说明](bilibili-dm.md)。本轮新增能力均按离线契约实现，未以真实账号发布、投币或修改资料。

## 如何启动

沿用私信接入说明的 Node 24+、`BILI_SELF_ID`、`BILI_COOKIE`、`BILI_ONEBOT_TOKEN`。只在授权范围内使用；网页版接口不是稳定的开放平台契约。Cookie 仅注入协议端，不传给模型。按需要选择模式：

| 命令（在项目根） | 实际权限 |
|---|---|
| `npm run start:bili` | 原模式：指定对端文本私信、默认只读 |
| `npm run start:bili -- --account-actions` | 账号查询和直播间订阅，不向 B站写入。可不设 `BILI_PEER_ID`，即不读取私信基线或轮询收件箱 |
| `npm run start:bili -- --account-actions --allow-account-writes` | 加入账号写操作，包括投币、发动态、改个人资料；不要把这个实例的令牌给不受信任的运行端 |
| 上一行另加 `--browser-comments` | 开启可选的 Chromium 评论动作。设置 `BILI_BROWSER_DRIVER_PATH` 为受信任的本地 Playwright 驱动 JS 入口绝对路径，`BILI_BROWSER_EXECUTABLE_PATH` 为 Chromium 可执行文件路径 |

`--allow-send` 仍**仅授权原有指定对端文本发送**；不会开启投币、关注、评论等动作。私信扩展始终绑定 `BILI_PEER_ID`；发送图片、撤回等还需同安装的 UUIDv4 `BILI_DEVICE_ID`。不做任意 URL 代理、磁盘文件读取或私信全量归档。图片通过受限的图片数据或动作支持的 B站图片引用传入。

### 在当前实例发现并调用动作

不配置任何账号，也可先运行 `npm run catalog:bili` 查看编译进源码的完整扩展动作清单。它不联网、不初始化浏览器；与下述在线目录不同，源码清单并不代表当前账号拥有权限。

使用与现有协议相同的 **`POST /` + Bearer token** 或带鉴权的 WebSocket，默认本机 `127.0.0.1:13810`。可以先发：

```json
{"action":"bili_action_catalog","params":{},"echo":"discover"}
```

`data` 是当前实例可用的账号动作，每项含 `name`、`write`；有契约元数据时也给 `params`。字段类型和默认值看下面分册。标准 `get_supported_actions` 仍给出全部可调用的动作名。没有启用浏览器就不会把发评论列为可用，没有配置私信对端就不会提供私信扩展。只读实例拒绝写入；这是执行约束，不只是隐藏菜单。

```json
{"action":"bili_video_info","params":{"bvid":"BV1xx411c7mD"},"echo":"example"}
```

读取成功与提交成功的判断依据是上游业务响应，不是 HTTP 200 本身。`retcode=1504` 表示副作用不确定，不可自动重试；`1429` 表示当前写入繁忙或冷却中。收费、消耗硬币、公开可见、更改关系的动作，须由账号操作者明确授权。遇到平台验证或鉴权失败按错误处置，不切换账号、地址或签名策略重试。

## 交付范围（对应研究矩阵）

| 矩阵 | 工程入口与边界 |
|---|---|
| R1–3、R5–8、R11–17、R21–24 | 视频详情、播放地址、历史弹幕、评论翻页与楼中楼、房间详情、空间/用户、关系、收藏、历史、稍后再看、消息通知、动态流、搜索：[查询与社交动作](bili-social.md)。播放地址不是下载器或绕过付费权限。通知按页查询，不是后台推送。 |
| R4 | 普通视频没有对应的实时弹幕长连接；不把历史弹幕伪装成实时事件。 |
| R9–10、W1 | [直播动作与事件](bili-live.md)：订阅、取消、认证就绪、弹幕、礼物、榜单/人气和发文本弹幕。建立连接不等于认证成功，须看状态事件。 |
| R18–20、W14 | [文本私信](bilibili-dm.md)及[私信扩展](bili-publish.md)：指定会话列表投影、历史、标已读、图片发送、撤回；不会通过动作参数改收件人。 |
| W2–4 | [普通弹幕发送/撤回](bili-social.md)；[互动弹幕组件创建/删除](bili-social-profile.md)，仅账号有相应稿件权限时可用。 |
| W5–7 | [独立浏览器评论](bili-browser-actions.md)处理视频主评论与回复；点赞、撤销点赞、删除走[评论动作](bili-social.md)。账号可否操作、评论是否需要审核由平台决定。 |
| W8–13 | [视频与关系动作](bili-social.md)：点赞、投币、收藏、三连、分享记录；关注/取关、拉黑/解除、移除粉丝；另有稍后再看和收藏夹管理。分享记录不等于向好友转发。 |
| W15–21 | [内容发布](bili-publish.md)：文本/图文动态、图片上传、转发、投票创建、专栏草稿和发布/编辑、封面。草稿和公开发布是不同动作。 |
| W24 | [个人资料](bili-social-profile.md)：查看和修改资料、签名、头像；改昵称需要额外确认。 |
| W22–23 | 按排除视频投稿链处理：不上传视频，不提交视频稿件，不换源或改视频稿。专栏、图文动态不在此排除项内。 |

[社区扩展](bili-community.md)覆盖矩阵之外的常用内容互动；[内置机器人工具配置](bili-runtime-tools.md)说明如何把指定动作授权给模型。这里的范围是研究矩阵及明确列出的扩展，不代表钱包、购物、实名、账户安全、每种客户端或创作中心专用功能已经接入。

## 验证分层

- `npm test`：参数与请求契约、错误语义、作用域、现有私信及 QQ 回归；不要求真实登录。
- `node --test test/bili-account-service.test.mjs`：真实 localhost OneBot HTTP 服务，检查默认只读、目录过滤、账号专用模式、一次写入结果未知及资源释放，上游为夹具。
- 浏览器评论、直播帧和内置运行端各有单独的本地验证方法，见对应分册。离线 Chromium 操作不是当前 B站页面适配性的证明。
- 真机验收以后按分册逐项进行，先查询，再用自己的测试内容做可逆互动；公开发布、消耗硬币、修改资料另行授权。不得把此前文本私信的真实收发证据外推给这些新动作。
