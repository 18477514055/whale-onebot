# Whale OneBot 1.2.20（versionCode 12021）发布说明 —— P0 拟人化底座与知识库/记忆认知升级

本版本为《拟人化系统工程与记忆/知识库认知升级》三期规划的 **第一期（P0）交付**，在严格守护既有 12.4 万段知识库与 660 条记忆零破坏平滑兼容的基础上，落地群聊社会动力学、三段式对数正态时间学、知识库结构化增量/影子升级与统一工作记忆预算引擎。

## 核心升级

### 1. 群聊社会动力学与关闭思考主模型 Lite-ToM 路由（`[layer: core-bot]`）
- 新增 `input/agent-app/src/core/group-dynamics.js` 并接入 `orchestrator.js`：
  - **对话粘性窗口（120s 指数衰减）**：回复某位群友后激活 120 秒对话粘性，对方顺势接话且未 `@别人` 时不再被静态群概率随机掐断；一旦明显 `@他人` 立即清零粘性；
  - **自适应连发防抖（3~6s，上限 12s）**：识别起手短句与连发消息窗口，等对方说完再合并回复；
  - **五档分层动作空间 + 关闭思考主模型 Lite-ToM 路由**：私聊与被 `@` 零开销短路直通 `FULL_TURN`（保持敏捷不敷衍）；群聊未 `@` 的窗口合并后，纯复读水群低频节流，其余走关闭思考的主模型输出 `SILENT_ABSORB` / `REACTION_ONLY`（调用原生 `set_msg_emoji_like`）/ `BACKCHANNEL`（1~4 字微附和）/ `DEFERRED_JOIN` / `FULL_TURN`；识别出对方处于吐槽倾诉（`venting`）时自动引导共情，抑制爹味清单说教。

### 2. 三段式对数正态时间学、微交互与严肃场景熔断（`[layer: core-bot]`）
- 改造 `onebot/sender.js` 与 `tools/tools-core.js`：
  - **三段式对数正态延迟**：拆分为 `preTypingMs = T_notice(LogNormal) + T_read(字数/图片/语音)` 与 `typingMs = T_type(逐气泡打字 + 停顿抖动)`，**私聊仅在读完进入打字段才亮起「正在输入…」**；
  - **发前 100ms 过时中止检查**：群聊非直呼插嘴在等待期被大量新消息冲过时，自动中止发送过时草稿；
  - **长工具链先占楼（> 3.5s）**：私聊/被 `@` 调用联网搜索或查资料超过 3.5 秒自动先发一句口语过渡气泡；
  - **同轮零额外调用延迟追补（`afterthought`）** 与 **严肃/技术/排错场景自动熔断**（自动关闭延迟追补、犯困敷衍与刷梗）。

### 3. 知识库结构切片、零成本上下文前缀、元认知书架、HyDE 与影子表安全老库升级（`[layer: core-bot]` + `[layer: shell-android]`）
- 升级 `features/knowledge-lib.js` 与新增 `features/knowledge-upgrade.js`：
  - **结构感知切片 + 零成本前缀**：解析 Markdown `#/##/###/####` 标题路径，完整保护代码块与表格不腰斩，每块前置 `[库名 > 文件名 > 标题路径]`；
  - **`sha256` 增量索引与元认知书架（`kb_manifests`）**：未变更文件秒级跳过；自动为现有老库补建 30~60 字书架摘要与高频实体词常驻上下文，解决「有库不知查 / 无库瞎调用」；
  - **自适应查询路由 + 低置信度 HyDE 复查 + 诚实拒答**：按专有名词/口语调整关键词与向量权重，低置信度自动走关闭思考主模型改写复查 1 次，仍低分显式警告禁止编造；
  - **老库后台分批静默升级（影子表安全铁律）**：全程写入独立 `docs_stage` 并逐源落盘断点，缺失源文件时按现役 `docs.source` 原地聚合升级并附带章节摘要；**严格校验新数据完整可读后才在单事务内原子切换，确认可用前绝不清理任何旧数据**；
  - Android `KnowledgeScreen.java` 新增书架摘要展示与后台影子升级进度条 / 暂停 / 继续控制。

### 4. 统一工作记忆竞争上屏与自然化回忆呈现（`[layer: core-bot]` + `[layer: shell-android]`）
- 新增 `memory/working-memory.js` 并接入 `llm/prompt.js`：设立硬性 Token 总预算（群聊默认 1200 / 私聊 1800），统一按综合激活分竞争上屏，自动标注 `[清晰记得]` / `[隐约记得]` 与 `[来源: 本群/跨群/私聊]`，在群聊中对 `private:` 来源记忆执行 100% 硬拦截。
- Android `BotConfigSchema.java` 在现有区块内克制补齐 P0 核心开关（不增顶层入口）。
