### 4.1 两条片子的分镜

**B站 90 秒（1920×1080 / 30fps，技术向）**

| 时间 | 画面 | 字幕 | 动效 |
|---|---|---|---|
| 0–6s | 黑场起，鲸鱼图标亮起，主标题浮现 | 手机就是服务器｜Whale OneBot 1.1.0 Beta | 图标呼吸光、标题逐字上浮 |
| 6–16s | 三张否定式文字卡：不用服务器 / 不用公网 IP / 不用常开的电脑 | 一台旧手机，够用 | 文字替换、细线划过 |
| 16–30s | 手机框内：首页 → 机器人列表 → 启动页 | 登录、配置、看板，都在这一部手机里 | 缓慢推镜 + 卡片错位入场 |
| 30–46s | 配置面板 → 模型 → 人格 → 知识库/记忆 | 人格、记忆、知识库、模型，按用途分开配 | 横向平移、局部放大 |
| 46–60s | 看板：实时 / 心跳 / 心情精力 / 今日用量 | 它现在什么状态，看得见 | 数字滚动、进度条生长 |
| 60–72s | 架构示意图：App 容器 ←→ QQ 开放接口（实线）；"往 QQ 进程里塞东西"（打叉） | 不注入、不 Hook —— 走 QQ 开放的接口 | 线描动效、叉号落下 |
| 72–82s | OneBot 11 标识 + 协议端 + 虚线框「抖音 / 小黑盒 · 规划中」 | 也可以只拿协议端，接你自己的机器人 | 虚线浮现、标签淡入 |
| 82–90s | 环境配置页 → 落版：Release 链接 + 「搜 Whale OneBot」+ Beta 小字 | 设置 → 环境配置，装好就能跑 | 收束、logo 落版 |

**抖音 30 秒（1080×1920 / 30fps，大众向）**

| 时间 | 画面 | 字幕 |
|---|---|---|
| 0–3s | 满屏大字，深色底 | 旧手机别扔，它能当机器人服务器 |
| 3–10s | 手机框：首页 + 机器人列表 | 装一个 App，就是一个 QQ 机器人 |
| 10–20s | 看板 / 知识库 / 人格快切（约 1.2s 一切） | 有人格、有记忆、有自己的知识库 |
| 20–26s | 极简架构图 | 通过 QQ 开放的接口接入，不用折腾协议 |
| 26–30s | 落版 | Whale OneBot · 搜就有｜Beta 版，仍在完善 |

### 4.2 技术路线

1. **一套数据驱动两版**：`compose/scenes.mjs` 存分镜（时间码、文案、素材、动效参数），`compose/frame.html` 暴露 `window.__frame(t)`，headless Chrome 按时间轴截帧，ffmpeg 合成 MP4。16:9 与 9:16 只是两套布局参数。
2. **截图脱敏**（本轮唯一会碰像素的环节）：Python + Pillow —— 先按固定值裁掉状态栏（1080 宽下约 110px），再对号码/昵称区域取邻近底色做同色铺底，用 `msyhbd.ttc` 重绘演示值；处理结果落 `docs/promo-1.1.0-beta/assets/`，原始截图不动。
3. **音频**：Node 生成 WAV（低频 pad 两层 + 转场脉冲 + 轻微高频噪声铺底），ffmpeg 混流；不做人声。
4. **字幕**：硬字幕由同一份文案数据在 HTML 里渲染，保证视觉统一；`.srt` 从同一份数据导出，时间轴与画面天然对齐（避免"字幕和画面各算一套"）。
