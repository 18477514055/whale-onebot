# Whale OneBot 1.2.0

这是**正式版**（1.2.0）。相对 1.1.7／1.1.8 系列，这一版加了一整层新能力，并重做了界面。

## 一、新能力：无服务器 P2P 扫码远程控制

- **设备切换胶囊条**：首页顶部居中的胶囊条列出已配对设备，点进去是「远程设备」页；子页标题下会用小字标出当前看的是哪台远端。
- **扫码配对**：`Camera2` 实时扫码 + 相册选图 + 手输口令三条入口都可用（纯 Java 解码，不依赖 Google 服务）。
- **零自建服务器**：配对与打洞走 4 级回退 —— mDNS → IPv6 直连 → STUN + 多节点加密公共信令 → 自定义兜底。
- **端到端加密**：ECDH 协商 + AES-256-GCM 传输，BIP-340 Schnorr 签名；配对用 **60 秒单次密钥**，过期即废，防重放。
- **36 个页面远程透明适配**：不是只做首页 —— 备份、deb 流式传输、QQ/B 站扫码、全配对机后台心跳都走同一条链路。
- **可读写完整配置**（含模型 Key），但**日志零明文**。

## 二、界面重做

- **默认主题改为 `dawn`（晨纸）浅色**。老用户已选过的主题**不会被覆盖**。
- 全链路统一卡片：白色圆角卡 + 1dp 分割线 + 状态胶囊 + 友好短名（不再把 41 字符 UUID 直接摊在列表里）。
- 四个入口彻底拆清、消灭同名套娃：版本管理页内就地闭环、备份做成三段式中心、环境配置按未装/已装两态折叠、核心维护拆 3 卡并自动算存储。
- 进度统一成「MB + 百分比 + 阶段文案」。
- 全仓原生 `AlertDialog` **清零**（最后 1 处已迁到统一弹层）。

## 三、部件版本化（这一版的结构性改动）

从 1.2.0 起，**App 与各内置部件各有自己的版本号，部件的更新不再依赖 App 更新**：

| 部件 | 本版版本 | 说明 |
|---|---|---|
| App（外壳） | 1.2.0（12001） | 就是你装的这个包 |
| 运行环境 | 1.1.8 | 未变（源码自 1.1.8 起未动，按「只随变了的那个跳版本」不跟着跳） |
| 内置核心（含唯一的 OneBot 11 契约层） | 1.1.8 | 未变 |
| 平台插件 · QQ / B站 | 1.1.8 | 未变 |
| **平台后端 · QQ** | **1.2.0-beta.1** | 新：首次作为独立产物发布 |
| **平台后端 · B站** | **1.2.0-beta.1** | 新：首次独立，**自带 ws 依赖，不再寄生在 51 MB 环境包里** |
| **桌面协议端** | **1.2.0-beta.1** | 新：`src/` 整棵树，给 Linux/Windows 与旧路径用 |

- `release-index.json` 升到 **v2**：新增 `components{}` 按部件索引；**同时保留旧的 `releases[]` 字段**，
  所以已装 1.1.x 的用户读索引不会出问题。
- 版本管理页新增「内置部件（各自独立版本）」卡：逐部件显示版本、体积、状态，带下载地址的可以直接下载
  （下载只信索引里写的 sha256 与长度，镜像只是传输层，校验不过就换下一个候选）。

## 四、怎么装

1. 下载 `whale-onebot-1.2.0.apk`（release 签名，无 `debuggable`）。
2. 直接覆盖安装即可，**不需要卸载**：环境、核心、QQ 客户端与登录态、知识与记忆库都会保留。
   - 换环境时旧环境里的 `opt/QQ` 会先暂存、铺完再放回，所以**不会要求你重新下载 QQ**。
3. 第一次启动 1~2 分钟（铺内置环境），之后秒级。

## 五、本版已验证 / 未验证（如实写）

**已做过的**：
- `javac` 全量编译通过（139 个 Java 文件）；`node scripts/run-java-logic-tests.mjs` 全绿，
  其中新增 `ComponentIndexTest` 21 项、`RemoteP2pAndQrTest` 37 项。
- 三个包逐个核过包名 / versionCode / `debuggable` / 签名指纹 / sha256。

**没验证的（请当它没验过）**：
- **这一版还没装到真机上跑过**（大文件只能走 USB，当时链路不通）；真机验证的是上一版 1.1.8。
- 干净手机端到端（首次安装 → 起容器 → 装 QQ → 扫码 → 进群）**没有跑通过**。
- P2P 跨 NAT 打洞**没有在两个不同网络下的真机实测**。
- 两个新平台后端产物**目前只做到「能下载、能校验」，还没有代码把它们装进容器**。
- 525 个 gui `.so` 未裁剪，包体仍 ~104 MB。
